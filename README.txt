3D Puzzle Master - Android Studio project

What it is:
- Colorful 15-puzzle game for Android.
- On-screen arrow controls and tap-adjacent-tile controls.
- Move counter, timer, solvable shuffle, and new-game button.

Build an APK:
1. Install Android Studio on a computer.
2. Open this folder in Android Studio (File > Open).
3. Allow Gradle sync to finish. If prompted, install Android SDK Platform 35.
4. Select Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Android Studio will show a notification with the APK location. Usually:
   app/build/outputs/apk/debug/app-debug.apk

This is source code for building the APK; it is not itself a compiled APK.
